# 中文导读

作者：Liang Song。英文论文：[Pólya's inequality for the third planar Dirichlet eigenvalue](paper/third-eigenvalue/paper.pdf)。

论文研究任意有限正面积平面开集的第三 Dirichlet 特征值，主张 |Ω|λ₃(Ω)>12π，按完整重数排列，允许孔洞、不连通和无界。它不声称解决所有指标的 Pólya 猜想。

证明的第一步是把面积缩放为 1，再沿一条面积平分线切开并镜像反射。每侧若有小的第二偶特征值，就能找到两个不相交的低能量部分。第一条剖面估计迫使这两个部分在切线旁的条带里占据足够面积。

旋转平分线，直到两侧紧邻条带的面积相等。如果共同面积小，第一条估计排除两侧低能量。如果共同面积大，原区域大部分面积已在整条带里；改用垂直平分线，条带外的剩余面积控制第二条剖面估计中的宽度超出量。两种情形给出同一结论。

正文独立给出上述论证、辅助估计和有限计算的数学准则。计算补充材料另提供精确数据、程序、Lean 源码与复现说明。读正文不需要在程序文件之间来回跳转。

当前 Lean 只证明九个新的辅助定理及旧版条件接口；整篇 PDE 主定理尚未形式化。完整覆盖表见 [SCOPE.md](SCOPE.md)，复现步骤见 [VERIFICATION.md](VERIFICATION.md)。

这次版本修正了小窗口验证中 Bessel 零点区间构造的错误，九个区间重新通过；严格下界的显示也改为向下截断。旧版本与修正记录均保留，见 [ERRATA.md](ERRATA.md)。
