# Version 0.2.0 — 22 October 2026

This release focuses the repository on **Pólya's inequality for the third planar Dirichlet eigenvalue**, by **Liang Song**.

- Adds the English PDF and complete LaTeX source, with the mathematical argument and finite verification criteria in the article.
- Adds nine Lean auxiliary theorems, alongside the earlier explicit conditional interfaces.
- Corrects the small-window verifier's Bessel-zero enclosure and replays all nine parameter boxes and their corrupted-node control.
- Adds certificate input validation, exact checks for the corrected root bracket, complete axiom reporting, and fresh replay evidence.
- Replaces rounded approximations used as displayed lower bounds by downward-truncated values.
- Preserves the earlier torus material and release history.

The full spectral/PDE theorem is not yet formalized in Lean. The general all-index Pólya conjecture is not claimed. See SCOPE.md and ERRATA.md for precise qualifications.
